## 产品定位

言道（Gendou）是一款面向中文母语用户的多语言超级学习平台，集**成瘾性游戏化学习**、**搞怪情绪反馈**、**分销裂变赚钱**与**创始人隐藏后台**于一体，战略上对标并全面超越多邻国（Duolingo）。

## 核心功能架构

### 1. 开屏漏斗问卷（中文全局化）

用户首次打开应用，迎面而来的是**全中文开屏弹窗**：

1. **语种对齐页**：母语固定为 🇨🇳 中文，横向滚动 10 国语言卡片选择目标语言
2. **目标选择页**：日常交流 / 专业考级 / 职场外语
3. **智能分流页（核心）**：
   - 🌱 零基础小白 → 动画直接进入，无需答题
   - 📊 有基础 → 3 道中文定级题自动测级
4. **主页动态锁定**：问卷完成后主页自动切换到用户选择的语种

**重置入口**：用户中心底部"重置问卷"按钮，创始人测试专用。

### 3. 游戏化学习场（Game-Based Learning Arena）

#### 3.1 连线消消乐（Vocab Match-Up）
- 左列中文 vs 右列目标语言，点击配对
- 点击触发**果冻弹性缩放**动画（cubic-bezier 弹性曲线）
- 配对正确：卡片 pop 消失 + 撒花彩带 + 金色 "+20 XP" 粒子浮起
- 配对错误：卡片剧烈**左右颤抖**（带旋转）+ 红光闪烁 + 扣血

#### 3.2 拼图连词成句（Sentence Puzzle）
- 打碎的外语词块以气泡方块呈现
- 用户依次点击词块拼出正确语法顺序
- 答对绿光，答错红光 + 允许重试

#### 3.3 进入前 10 秒大咖攻略
每次进入关卡弹出语言专属速成窍门（如日语：动词永远在最后！），10 秒倒计时或点击跳过。

#### 3.4 成瘾性反馈系统
- **❤️ 生命值血条**（5 颗心）：答错扣 1 颗，耗尽提示邀友补血
- **⚡ 连胜 Combo 条**：3 连胜显示 "⚡ COMBO x3" 浮现动画，5 连胜触发 "🔥 BLAZING x5" + 撒花彩带

#### 3.5 氛围切换（Vibe Check）
| 模式 | 答对反馈 | 答错反馈 |
|------|----------|----------|
| 🧸 纯真搞笑 | "针不戳！智商占领高地了！" | "大意了没有闪！柴犬已流泪！" |
| 🔥 欢喜冤家 | "哎哟不错哦，脑子也挺好使的嘛❤️" | "笨蛋！罚你大声朗读三遍！💢" |

答错时 **Web Speech API 自动朗读**正确答案（按目标语言口音），强化记忆。

---

### 4. 语法 & 词汇深度库

四个标签页：
1. **语法**：句型卡片，展开查看结构 + 例句 + 中文注解
2. **词汇**：高频词 / 行业词 / 考核词三类，支持搜索过滤
3. **变形**：动态词形推导链（如日语 食べる → 食べます → 食べた → 食べない → 食べて），逐步揭示 + 通俗中文解释
4. **章节**：按主流教材（新标日 / 延世韩语 / Reflets 法语等）分章进度条

---

### 5. 病毒式分销裂变系统（Earn While You Learn Hub）

**用户中心**（底栏"我的"或顶栏头像）：

#### 5.1 专属邀请卡
- 深色卡片展示专属邀请码（`YD-XXXXXX`）
- 一键复制推荐链接
- 分享海报按钮（演示模式：+1 邀请）

#### 5.2 实时收益看板
| 数据 | 说明 |
|------|------|
| 成功邀请好友数 | 完成验证 + 打卡 3 天的有效邀请 |
| 已赚取现金 | 美元计价，一键提现按钮 |
| 钻石奖励 | 可兑换内购道具或生命值 |

#### 5.3 赚钱规则
1. 每邀请 1 位好友下载打卡 → 立即 **$2 现金**（金额由创始人后台调控）
2. 好友未来充值任何内购 → **终身 30% 现金裂变抽成**（比例由创始人后台调控）
3. 邀请满 10 位 → 解锁**钻石会员**，全站免费

#### 5.4 防薅羊毛安全公示
> ⚠️ 每位被邀请的好友必须通过手机验证、且在应用内打卡学习满 3 天，奖金方可解冻提现。每个设备限领一次。

#### 5.5 机构合作广告位
用户中心内嵌**机构特惠推荐横幅**（如新东方在线 JLPT N2 冲刺班），精准触达学习意图用户。

## 动态内容扩充指南（无需改代码）

### 批量导入题目与词汇

编辑 `src/data/dynamic_content.json`，按已有模板追加数据：

```json
{
  "vocab_pairs": [
    {
      "id": "ja_003",
      "lang": "ja",
      "zh": "美丽",
      "target": "きれい",
      "morphology": { "base": "きれい", "steps": [...] },
      "vibe_pure_correct": { "emoji": "🐱", "title": "...", "body": "..." },
      ...
    }
  ],
  "sentence_puzzles": [
    {
      "id": "ja_puzzle_002",
      "lang": "ja",
      "zh": "你叫什么名字？",
      "words": ["なんですか", "お名前", "は"],
      "answer": ["お名前", "は", "なんですか"],
      "tip": "..."
    }
  ]
}
```

系统会**自动合并**到游戏内容池，无需重启或修改代码。

### 添加搞怪配音

将音频文件放入对应目录，命名为 `1.mp3`, `2.mp3`, `3.mp3`…：

```
public/
  audio/
    success/   ← 答对时随机播放
      1.mp3    （例：猫咪欢呼声）
      2.mp3    （例：撒花音效）
      3.mp3    （例：合唱 "太棒了！"）
    failure/   ← 答错时随机播放
      1.mp3    （例：柴犬叫声）
      2.mp3    （例：喜剧 "哎呀" 音效）
      3.mp3    （例：卡通打击声）
```

系统会随机抽取播放，文件不存在时**静默失败**，不影响任何功能。

## 数据库结构（Supabase）

| 表名 | 说明 |
|------|------|
| `user_profiles` | 用户开屏问卷结果（语种、目标、等级、session_key、ui_language）|
| `languages` | 10 种支持语言的元数据 |
| `grammar_patterns` | 各语言语法句型库 |
| `vocabulary_items` | 各语言词汇库（含行业分类）|
| `survival_scenarios` | 主页情境场景卡片 |
| `exam_questions` | 模拟考试题库 |
| `weekly_xp` | 每周 XP 记录（用于排行榜）|
| `streak_shields` | 连胜护盾库存 |
| `daily_tasks` | 每日任务进度 |
| `monthly_badges` | 月度徽章记录 |
| `friendships` | 好友关系（pending/accepted/declined）|
| `friend_joint_tasks` | 好友共同任务 |
| `user_achievements` | 成就解锁记录 |

所有表均启用 **Row Level Security (RLS)**，用户仅可读取自己的档案数据。
